# VF_PLUS

Небольшая аркадная игра на Godot — арена, игрок, паттерны атак, уровни на JSON.

## Требования

(Для собственной сборки:)
- Godot 4.X
  
(Для запуска игры:)
- Скачать версию для вашей платформы с relases
- Запустить/Установить

## Структура проекта

    core/
        game_manager.gd      — автолоад, сканирует папки уровней, запускает уровень
        pattern_manager.gd   — читает таймлайн уровня, создаёт и запускает паттерны
    entites/
        player.gd            — игрок, движение за мышью
        bullet.gd            — базовый снаряд
        arena.gd             — сцена арены, пауза, рестарт, экран смерти
        attacks/             — скрипты паттернов атак
    scenes/
        menu/                — главное меню, список уровней
    levels/                  — встроенные уровни
    assets/                  — спрайты, шрифты, звуки

## Как это работает

GameManager при старте сканирует папки уровней и отдаёт список в меню.
При выборе уровня PatternManager читает JSON, выстраивает таймлайн событий
и по каждому событию вызывает соответствующий скрипт паттерна из entites/attacks.
Паттерны спавнят пули через общую сцену BULLET_SCENE, читают параметры
из JSON и уважают паузу/смерть игрока.

## Моды и кастомные уровни

Вы можете создать собстенные паттерны (.gd) или уровни (.json)
и разместить в папках patterns и levels рядом с исполняемым файлом игры.
