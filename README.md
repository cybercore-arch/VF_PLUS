# VF_PLUS

Небольшая аркадная игра на Godot — арена, игрок, паттерны атак, уровни на JSON.

## Структура проекта

    core/
        game_manager.gd      — автолоад, сканирует папки уровней, запускает уровень
        pattern_manager.gd   — читает таймлайн уровня и запускает паттерны
        pattern_util.gd      — PatternUtil: общие функции для паттернов (пауза, позиции, цвета, спавн)
    entites/
        arena/               — сцена арены, пауза, рестарт, экран смерти
        bullet/              — базовый снаряд
        player/              — игрок, движение за мышью
        attacks/             — скрипты паттернов атак
    scenes/
        menu.tscn, menu.gd   — главное меню, список уровней
    levels/                  — встроенные уровни
    assets/                  — спрайты, шрифты, звуки

## Как это работает

GameManager при старте сканирует папки уровней и отдаёт список в меню.
При выборе уровня PatternManager читает JSON, выстраивает таймлайн событий
и по каждому событию вызывает соответствующий скрипт паттерна из entites/attacks.
Паттерны наследуются от RefCounted, спавнят пули через PatternUtil, читают параметры
из JSON и уважают паузу/смерть игрока.

## Моды и кастомные уровни

Вы можете создать собственные паттерны (.gd) или уровни (.json)
и разместить в папках patterns и levels рядом с исполняемым файлом игры.
При запуске из редактора эти папки лежат в корне проекта.

## Экспорт

В Export → Resources → *Filters to export non-resource files/folders* добавь `*.json`,
иначе встроенные уровни не попадут в сборку.
