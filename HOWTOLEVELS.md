# Как собрать уровень

Уровень — это JSON-файл. Игра читает две папки:

- `res://levels/` — встроенные уровни, попадают в сборку.
- `<папка с игрой>/levels/` — пользовательские уровни, лежат рядом с исполняемым файлом.

При запуске из редактора Godot вторая папка — это корень проекта, то есть `res://levels/` и просто `levels/` совпадают. При запуске собранной игры `levels/` — это папка рядом с `.exe`.

> **Для экспорта:** в Export → Resources → *Filters to export non-resource files/folders* сделаю позже `*.json`, иначе встроенные уровни не попадут в сборку. 

## Категории уровней

Уровни делятся на три списка в меню:

- **Official** — файлы из `res://levels/`, в имени которых нет `test` и нет `ENDLS`.
- **Custom** — файлы из `<папка с игрой>/levels/`, в имени которых нет `ENDLS`, плюс тестовые уровни из `res://levels/` (в имени есть `test`).
- **Endless** — любые файлы из обеих папок, в имени которых есть `ENDLS`.

Это значит, что имя файла влияет на то, куда он попадёт. `ENDLS` и `test` — служебные маркеры.

## Формат

Корень JSON — объект с одним обязательным полем `events`.

    {
        "events": [
            { "time": 0.5, "pattern": "shot", "params": { "target": "player", "speed": 200 } },
            { "time": 1.5, "pattern": "circle", "params": { "count": 12, "speed": 150 } },
            { "time": 3.0, "pattern": "spiral", "params": { "duration": 2.0, "tick_interval": 0.1 } }
        ]
    }

Поля уровня:

- `events` — массив событий. После загрузки они сортируются по `time`, так что порядок записи в файле не важен. При одинаковом `time` сохраняется порядок из файла.

### Событие

- `time` — момент срабатывания в секундах от старта уровня.
- `pattern` — имя скрипта паттерна без `.gd`. Должно совпадать с именем файла в `entities/attacks/` или в папке `patterns/` рядом с игрой. Только имя файла, без путей.
- `params` — объект параметров. Если паттерн не получил параметр, он использует значение по умолчанию. Если `params` отсутствует, передаётся пустой объект.

## Обработка параметров

Перед вызовом паттерна параметры проходят через `PatternUtil.prepare_params`:

1. Все массивы из 3–4 чисел превращаются в цвета. Это работает на любой глубине, в том числе внутри `params` паттерна `loop`.
2. Если в `params` есть поле `pos`, оно превращается в `Vector2`.

### Цвета

Если значение параметра — массив из 3 или 4 чисел, оно превращается в `Color`. Формат: `[r, g, b]` или `[r, g, b, a]`, каждое число от 0.0 до 1.0.

    "color": [1.0, 0.0, 0.0]        — красный
    "color": [1.0, 0.0, 0.0, 0.5]   — красный с прозрачностью

Строки как цвета не обрабатываются: `"#ff0000"` останется строкой, и паттерн сам решает, что с ней делать. Если хочешь строковые цвета — обрабатывай внутри паттерна.

### Специальные значения позиции

Параметр `pos` можно задать строкой, и она заменится на вектор:

- `"center"` — центр экрана.
- `"random"` — случайная точка в пределах вьюпорта, с отступом 50 пикселей от краёв.
- `"player"` или `"aimed"` — текущая позиция игрока. Если игрок не найден, возвращается центр экрана.

Если `pos` — массив из двух чисел, он превращается в `Vector2(x, y)`.

Другие поля (например, `target`) менеджер не трогает: паттерн сам разбирает их через `PatternUtil.resolve_point`, и поддерживает те же значения.

### Повторы с `loop`

`loop` запускает вложенный паттерн несколько раз:

    { "time": 0.0, "pattern": "loop", "params": {
        "target_pattern": "shot",
        "repeat": 5,
        "interval": 0.4,
        "reroll_pos": true,
        "params": { "pos": "random", "target": "player", "speed": 300 }
    } }

- `repeat` — число запусков, `0` или меньше значит бесконечно.
- `reroll_pos` — `true`: `"random"`/`"player"` в `pos` и `target` вычисляются заново на каждом запуске. `false` (по умолчанию): один раз в начале.
- `step_angle`, `step_speed` — сдвиг `start_angle` и `speed` с каждым запуском.

## Таймлайн

`PatternManager` идёт по событиям по порядку и срабатывает, когда `current_time >= event.time`. Одно и то же время у нескольких событий означает, что они сработают в одном кадре в порядке массива.

Таймлайн не зациклен. Чтобы повторить паттерн, используй паттерн `loop` или добавь несколько событий с разным `time`.

## Минимальный пример

    {
        "events": [
            { "time": 0.0, "pattern": "shot", "params": { "pos": [200, 100], "target": [200, 600], "speed": 300 } },
            { "time": 0.0, "pattern": "shot", "params": { "pos": [1080, 600], "target": [1080, 100], "speed": 300 } },
            { "time": 2.0, "pattern": "circle", "params": { "count": 16, "pos": "player" } }
        ]
    }

Первые два выстрела происходят одновременно навстречу друг другу. Через две секунды — кольцо из 16 пуль вокруг игрока.

## Отладка

- Уровень не появился в меню — проверь, что JSON валидный и лежит в правильной папке.
- Уровень есть, но ничего не происходит — проверь имена паттернов. Они должны совпадать с именами файлов в `entities/attacks/` или в `patterns/`.
- Паттерн вызван, но параметры не те — распечатай `params` внутри паттерна или проверь, что `pos` задан именно как `pos`, а не как `position` или `spawn`. Выстрел `shot` целится через `target`/`target_x`/`target_y`, а не через `angle`.
- Игра падает на загрузке уровня — скорее всего, JSON не парсится. Проверь запятые и кавычки.
